2.

Consent strings

Strings load automatically when the SDK is ready and update after consent changes. Use Refresh for a manual check. Read the encoded IAB Transparency and Consent (TC) and Global Privacy Platform (GPP) strings for this browser using Didomi.getCurrentUserStatus(). These are a snapshot of the current SDK state. The Didomi Consent String (DCS) below is read separately from this browser’s saved storage. Reading these strings does not accept, reject, or reset consent. A returned string alone does not mean the visitor agreed to everything.
